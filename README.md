Webshop Product Manager (Java, OOP, Swing, CSV) <br>
This project is a small Java desktop application that simulates a simple webshop product management system. <br>
It demonstrates solid object‑oriented design, inheritance, abstraction, file handling, and a graphical user interface using Swing. <br>
The application allows a logged‑in user to: <br>
• Add new products (Books, Clothes, Food) <br>
• Save products to a CSV file <br>
• List all saved products <br>
• Search for a product by name <br>
• Work with a clean UI menu system
