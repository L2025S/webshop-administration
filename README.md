Webshop Product Manager (Java, OOP, Swing, CSV)
This project is a small Java desktop application that simulates a simple webshop product management system.
It demonstrates solid object‑oriented design, inheritance, abstraction, file handling, and a graphical user interface using Swing.
The application allows a logged‑in user to:
• Add new products (Books, Clothes, Food)
• Save products to a CSV file
• List all saved products
• Search for a product by name
• Work with a clean UI menu system
